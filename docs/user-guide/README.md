# User guide

How to install OpenShell WebUI and use it to manage your OpenShell gateways from the
browser. No coding needed; you only need the `openshell` CLI with a registered gateway.

## Start here

1. [Getting started](getting-started.md): install, launch and open the WebUI.
2. [Concepts](concepts.md): gateways, workspaces, sandboxes, policies and providers in plain words.
3. [Navigation](navigation.md): find your way around the app.
4. [Sandboxes](sandboxes.md): create your first sandbox.
