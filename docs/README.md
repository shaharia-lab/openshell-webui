# OpenShell WebUI documentation

OpenShell WebUI is a local web UI for [OpenShell](https://github.com/NVIDIA/OpenShell)
gateways. These docs explain how to use it and how to work on it.

> [!NOTE]
> OpenShell WebUI is an unofficial community project. It is not affiliated with or
> supported by NVIDIA. For OpenShell itself, see the
> [official documentation](https://docs.nvidia.com/openshell/latest/index.html).
